# Historical artifact records

These files are original development records copied from the local `artifacts/`
folder. They identify artifacts that remain private and are **not** present here.
They may contain abbreviated or malformed checksum records and are preserved
literally as historical evidence, not repaired into supposed verification.

For this public source tree use the **root** `SHA256SUMS` and
`python -B tools/verify-publication.py`, not these legacy records. A recorded
private-image hash is not a download, a corresponding-source guarantee or a
redistribution license.
