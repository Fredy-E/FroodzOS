# boards/

Per-board files. Only `lenovo-83n3/` exists: the Lenovo IdeaPad Slim 3 15Q8X10 (83N3, Snapdragon X1-26-100).

- `kernel.config` — captured kernel configuration.
- `x126100-lenovo-ideapad-slim3.dts` — board device-tree source (BSD-3-Clause).
- `touchpad/` — the user-space touchpad polling driver and its service unit; background in
  [docs/touchpad.md](../docs/touchpad.md).
